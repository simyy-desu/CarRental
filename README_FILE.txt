##4Y's CAR RENTAL
##Car Rental Management System
The Car Rental Management System is a software platform  to automate and optimize the management of
 vehicle fleets, customer reservations, and rental return logistics.
This system aims to improve workflows for customer registration, vehicle availability checking, and
 booking processes. It is intended for both customers looking to rent various vehicle types (Economy,
  Luxury, and RV) and staff members who need to manage inventory and rental orders.
